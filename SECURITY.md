# Security Policy

## Scope

This is a privately maintained frontend website project.

- External code contributions are not accepted.
- Security reports are accepted privately.

## Supported Version

Security fixes are applied only to the latest deployed code.

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.

Report privately via:

- Email: `hamzauybatisha@gmail.com`
- GitHub Security Advisory: Repository `Security` tab -> `Report a vulnerability`

## What to Include

Please include:

- Vulnerability description
- Affected page/file
- Reproduction steps
- Security impact
- Proof of concept (if available)

## Response Targets

- Acknowledgment: within 24 hours
- Initial triage: within 3 business days
- Critical fix target: within 7 days

Timelines may vary based on severity and complexity.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before public
disclosure.
