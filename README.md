# Hamzauy Coaching Website

Official frontend codebase for the Hamzauy Coaching website.

## Project Status

- Maintained only by the project owner.
- External edits, pull requests, and feature contributions are not accepted.

## Structure

- `index.html` - main English homepage
- `ar/index.html` - Arabic homepage
- `payment/` - payment pages
- `free-plan-page/` - free plan pages
- `media/` - images, video, and favicon assets
